---
title: "Solución de problemas"
description: "Índice de las páginas de solución de problemas de ModularCore Hub."
---

Si algo no funciona como esperabas, empieza por identificar en qué punto del flujo estás:

- **[Instalación](/solucion-de-problemas/instalacion/)**: problemas al instalar o preparar el CLI (versión de Node.js, pnpm, permisos globales de npm).
- **[CLI](/solucion-de-problemas/cli/)**: errores que muestra `modularcore` al ejecutar `init`, `add`, `update` o `diff` (configuración de proyecto, compatibilidad de frameworks, dependencias).
- **[MCP](/solucion-de-problemas/mcp/)**: errores de configuración del servidor `@modularcore/mcp-server` cuando lo usa un cliente de IA.
- **[Registry](/solucion-de-problemas/registry/)**: errores de conexión con el registry HTTP y problemas conocidos de despliegue del propio Hub.

Si no encuentras tu problema en ninguna de estas páginas, revisa los [issues abiertos](https://github.com/yosnap/modularcore-hub/issues) del repositorio o abre uno nuevo con el detalle del error.
